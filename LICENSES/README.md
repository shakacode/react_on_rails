This repository has two license scopes.

1. [LICENSE.md](../LICENSE.md) contains the MIT License for the core React on Rails library.
2. [REACT-ON-RAILS-PRO-LICENSE.md](../REACT-ON-RAILS-PRO-LICENSE.md) contains The ShakaStack License, version 1.0, applied to React on Rails Pro.

The MIT core remains free for any use. React on Rails Pro is free in development, test, CI, and staging when used solely to prepare an application before production. Production use that serves real users or supports a live application requires ShakaStack Pro unless a free use applies. The subscription covers the whole organization across React on Rails Pro, ShakaPerf, and Inertia Rails SSR Cache without a size limit. Each product has its own free use rules.
